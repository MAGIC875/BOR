## 🚀 О проекте

### Что это

**Coworkly** — это веб-приложение, которое позволяет пользователям:
- Просматривать каталог коворкингов
- Смотреть детальную информацию о каждом месте
- Бронировать рабочие места в несколько кликов
- Управлять своими бронированиями

### Userflow (путь пользователя)
Главная → Каталог → Выбор коворкинга → Нажатие "Забронировать" → Подтверждение


**Кликов до бронирования:** 2

### MVP vs планы

| Функция | MVP | Статус |
|---------|-----|--------|
| Главная страница | ✅ | Готово |
| Каталог коворкингов | ✅ | Готово |
| Карточка коворкинга | ✅ | Готово |
| Бронирование по кнопке | ✅ | Готово |
| Страница "О сервисе" | ✅ | Готово |
| Адаптивный дизайн | ✅ | Готово |
| Поиск и фильтрация | ❌ | В планах |
| Личный кабинет | ❌ | В планах |

## 🔧 Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/your-username/coworkly.git
cd coworkly
```
Установка зависимостей

```bash
npm install
```

Запуск dev-сервера

```bash
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

Правила именования веток
Тип ветки	Формат	Пример
Основные	main, develop	—
Фича	feature/название	feature/coworking-card
Исправление	fix/название	fix/booking-button
Хотфикс	hotfix/название	hotfix/critical-error
Жизненный цикл

    Создать ветку фичи от develop

    Разработать фичу

    Создать Pull Request в develop

    Провести ревью (минимум 1 апрув)

    Смержить PR

    Удалить ветку фичи

Команды:

```bash
# Создать ветку фичи
git checkout develop
git pull origin develop
git checkout -b feature/my-feature

# Отправить ветку
git push origin feature/my-feature

# Создать релизный тег
git checkout main
git tag -a v1.0.0 -m "Release v1.0.0"
git push origin v1.0.0
```
